Сервис для получения данных из сводного реестра лицензий Росалкогольрегулирования.

## Алгоритм работы
1. Раз в N-й период через `/api/v1/licensee/refresh` запускается процесс получения данных Росалкогольрегулирования
2. Сервис по пути `rosalko.html-page-url` получает `html` страницу, откуда извлекает ссылку на zip архив
3. Скачивает архив и сохраняет в docstore
4. Информация о сохраненном файле передается через RabbitMq в transform-service
5. Transform-service парсит файл и перенаправляет данные в deduplicator-service для сохранения в справочник rosalko_licenses
